# Synthetic format and independent fixture arithmetic

**Every layout, name, code, scale, and difference in this file is invented.**
None describes a real J-message, DFI/DUI definition, or D-to-H change. The six
baseline labels exist only to exercise selection and isolation machinery.

## SYNTH-01

Input is a 16-bit logical integer. Bit 0 means the least-significant bit of
that integer. This is not a definition of capture byte order or a Link 16 word.

| Field | Internal bits | Toy interpretation |
|---|---|---|
| mode | 0–1 | 0 idle, 1 active, 2 invalid, 3 not_reported special |
| level | 2–7 | scaled unsigned; 63 is no_statement, never a measurement |
| auxiliary | 8–11 | unsigned when mode=1; 15 is unknown special |
| flags | 12–15 | 0 none, 1 set; other codes invalid |

The level multipliers are deliberately arbitrary:

| Demo identity | Invented multiplier |
|---|---:|
| D | 1 |
| E | 2 |
| F | 3 |
| F-C1 | 4 |
| G | 5 |
| H | 10 |

These numbers have no relationship to actual standard differences. All
scaled values use the artificial unit `test_units` and denominator 1.

## Hand-established normal case

The literal integer `0x0765` is 1893 decimal. Independent arithmetic gives:

```text
mode      = 1893 & 0b11        = 1
level     = (1893 >> 2) & 63   = 25
auxiliary = (1893 >> 8) & 15   = 7
flags     = (1893 >> 12) & 15  = 0
```

Expected level numerators are D=25, E=50, F=75, F-C1=100, G=125, H=250.
`fixtures/normal-cases.json` stores those literal expected outputs; they are
not generated by the Rust decoder. Rust tests repeat the small literal vector,
and the independent Python evaluator checks all fixture fields.

The Python evaluator and source compiler are distinct functions. Agreement is
useful software evidence but not independent verification of a military standard.
Rust execution has not occurred in this package's authoring environment.

## Exceptional cases

| Integer | Relevant expected behavior |
|---|---|
| 0x00fc | level raw=63 -> special no_statement, not 63×multiplier |
| 0x0764 | mode=0 -> auxiliary not applicable, raw 7 preserved |
| 0x0766 | mode=2 invalid -> auxiliary unresolved context |
| 0x0767 | mode=3 special -> auxiliary unresolved context |
| 0x0f65 | mode=1 and auxiliary=15 -> special unknown |
| 0x2765 | flags=2 -> invalid encoding |
| 0x10765 | exceeds 16 bits -> reject rather than truncate |

The H demo bundle also has `SYNTH-H-ONLY`: one 8-bit unsigned counter. Its
absence from D tests that lookup cannot fall back from D to H. The name is
explicitly synthetic; it asserts nothing about actual H-only message content.

## Typed test-only custom formats

Rust tests construct additional temporary toy layouts for full 128-bit extraction,
two's-complement boundaries, rational 1/3 scaling, overlap checks, and cycles.
Those dynamically constructed test bundles borrow identity fields for test
convenience; they are not released schema artifacts and their fingerprints are
not evidence of custom-bundle content. Production schema identities must be
created by the reviewed packaging path, not caller-supplied claims.
