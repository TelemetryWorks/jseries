# Scope and publication notice

This package contains project-authored generic software, synthetic test data,
and limited public catalog metadata. It includes no authoritative standard text
or real message dictionary. It is not endorsed by DLA, DISA, or a standards body.

Publication and software license selection remain project-owner decisions.
The Cargo crates have `publish = false`. No external repository has been changed.
Do not combine this package with controlled material without applying the
approved handling process for the combined result.
